我一直孜孜不倦地呐喊：提高效率、解放人力。在 GPT 出现之前，我呼喊用自动化脚本处理数据；GPT 出现之后，我又呼喊拥抱 AI。

但从去年下半年开始，一直有个尴尬的问题：对于那些不太关注技术发展、只想单纯使用 AI 的小伙伴，我到底该推荐什么产品？

Claude Code 和 Codex 当时都还是命令行界面；即便后来有了图形界面，安装、付费等环节依然存在门槛。

不过，我始终认为，这些原本为程序员写代码而设计的智能体，是最贴近通用智能体的形态。

原因很简单：我们日常使用 Adobe、Office 等软件处理文件，底层就是通过代码完成各种操作的。能够写代码、调用工具、操作文件的智能体，理论上也最有可能覆盖日常需求。

Codex 桌面版出来后，这种感觉更加强烈。我一直在期待一款国产的同类产品。

等了好久，终于等到腾讯的 WorkBuddy。

在我看来，腾讯其实是最适合做这类产品的公司。实际体验下来，WorkBuddy 里确实有几个很有意思的功能。

第一个是「助理」功能。

通过扫码就能绑定微信小程序、微信助理、微信客服号、企微助理、QQ 机器人……好家伙，这是把自家产品全打通了。

这里边我认为最方便的是微信助理，几乎就是便携版的「养龙虾」，绑定后在微信里就可以直接给 WorkBuddy 布置任务。

第二个是预置的技能和连接器。

既有腾讯自家的办公工具，比如腾讯文档、腾讯会议、ima 知识库，也支持钉钉、飞书等其他平台。看下来就一个感觉：包罗万象。

其实用户最关心的是 AI 能不能帮自己处理好手头的工作。至于什么是技能、什么是连接器，他们才不管嘞。

第三个是预置了多个模型。

作为 Codex 的高强度使用者，我大部分时间用的都是 GPT 系列模型；国产模型我只通过 DeepSeek 官方 API 接入过自己的一些工具。虽然最近国产模型发展迅速，但我一直没提起性子去尝试。

好在 WorkBuddy 里预置了不少，除了腾讯自家的 Hy3（目前可以免费用），还有 GLM-5.2、Kimi-K3、MiniMax-M3、DeepSeek。

趁着活动送了不少限时积分，我把这些模型都体验了个遍。不得不说，虽然腾讯的 WorkBuddy 产品做得不错，但它家的模型 Hy3 有点拉，还是老老实实做产品吧（笑）。

现在再有小伙伴问我，有什么好用的 AI 产品，我大部分时候首推 WorkBuddy，其次是 Codex。

两者在产品形态和功能上有不少相似之处，但 Codex 配上 GPT 模型，整体能力依然更强。即便使用相同的 Skill 和相同的提示词，Codex 对用户意图的理解、对 Skill 的命中能力，以及任务执行速度，通常都更稳定。

不过，我们在努力，差距也在缩小。加油呀。
